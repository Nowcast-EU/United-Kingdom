Accepted formats

Wide: first column = region, second = seats, every other column = a party's vote share (header row = party names).
Long: header row containing columns matching "constituency/province", "seats/magnitude", "party" and "share/vote".
Tab, semicolon or comma separated. Values can have a % sign; decimal commas work with tab or semicolon separators. If every value in the table is 1 or below, they are treated as fractions and multiplied by 100.

3. Monte Carlo runs

Constituency seats already won (this region)

Enter the number of constituency seats each party is projected to win in the selected region. They are treated as seats already won in the compensatory list allocation: a party's D'Hondt divisor is (constituency seats + list seats won so far + 1). Values are remembered per region.

Paste constituency seats for all regions at once

Header row: Region | SNP | Lab | Con | ..., then one row per region with that party's constituency seats. Regions are matched by name (accents and case ignored). Pasting replaces the stored values for each region listed.

Accepted formats

Either orientation is detected automatically. A single run is supported. Runs across columns: the header row is run numbers (1, 2, 3… or "Run 1"…) and the first column is party names. Runs down rows: header row is party names, and an optional first column holds the run number. Cells are regional list vote shares. Tab, semicolon or comma separated; % signs are fine; if every value is 1 or below they are treated as fractions and multiplied by 100. A run with a blank or non-numeric cell is skipped (the count is reported above).
List seats are allocated per run by compensatory D'Hondt on the vote shares: each party's quotient is votes ÷ (constituency seats won + list seats won so far + 1). In each run, a party below the legal threshold (set by MC_THRESHOLD, 0 by default for Scotland) wins no list seats. A row or column named "Others" is always shown as the right-most bar and never receives seats. Parties that are 0.0 in every run are left out of the chart.
Choosing a region sets the list seats to that region's magnitude from the hard-coded previous results table (PREVIOUS_RESULTS in the script; you can still overwrite the seats). PARTY_ALIASES maps a party to its name in that table, so the two are compared as the same movement, and adds that region's previous result behind each party's bar.

The chart can be sorted by projected result or previous result. When sorting by previous result, parties with a non-zero previous result appear first in descending order; parties with no previous result or a 0% previous result follow, sorted by projected result. "Others" remains last.

4. Nationwide Monte Carlo seat runs

Accepted format

The first row must contain run numbers (for example, 1, 2, or Run 1, Run 2). Put one party per row in the first column and that party's seat total for each run in the remaining columns. Seat totals must be whole numbers from 0 to 129. Incomplete or invalid runs are skipped.
