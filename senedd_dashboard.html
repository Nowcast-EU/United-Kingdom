Spanish election projection

Paste your table, pick a party, and compare its vote share in each constituency with the effective threshold.

1. Paste data

Accepted formats

Wide: first column = constituency, second = seats, every other column = a party's vote share (header row = party names).
Long: header row containing columns matching "constituency/province", "seats/magnitude", "party" and "share/vote".
Tab, semicolon or comma separated. Values can have a % sign; decimal commas work with tab or semicolon separators. If every value in the table is 1 or below, they are treated as fractions and multiplied by 100.

3. Monte Carlo runs

Accepted formats

Either orientation is detected automatically. A single run is supported. Runs across columns: the header row is run numbers (1, 2, 3… or "Run 1"…) and the first column is party names. Runs down rows: header row is party names, and an optional first column holds the run number. Cells are vote shares. Tab, semicolon or comma separated; % signs are fine; if every value is 1 or below they are treated as fractions and multiplied by 100. A run with a blank or non-numeric cell is skipped (the count is reported above).
Seats are allocated per run by D'Hondt on the vote shares. In each run, a party below the 3% legal threshold (set by MC_THRESHOLD) wins no seats. A row or column named "Others" is always shown as the right-most bar and never receives seats. Parties that are 0.0 in every run are left out of the chart.
Choosing a constituency sets the D'Hondt seats to that constituency's magnitude from the hard-coded previous results table (PREVIOUS_RESULTS in the script; you can still overwrite the seats). PARTY_ALIASES maps a party to its name in that table (currently FrA ↔ Sumar), so the two are compared as the same movement and adds that constituency's previous result behind each party's bar.

The chart can be sorted by projected result or previous result. When sorting by previous result, parties with a non-zero previous result appear first in descending order; parties with no previous result or a 0% previous result follow, sorted by projected result. "Others" remains last.
